# FinPulse Pro — 跨裝置多幣別個人金融與國債期貨資產中樞

FinPulse Pro 是一個專為跨國理財、多幣別現金流追蹤、國債/定存/期貨持倉管理與事前三情境試算設計的輕量級 PWA（漸進式網頁應用）。

採用**多頁面模組化架構**，可直接免費託管於 **GitHub Pages**，並預留 **Google Cloud Firebase Firestore** 免費額度同步接口。

---

## 📁 檔案架構（一頁一功能，省 AI Token 維護）

為避免單一檔案過於龐大導致每次修改消耗過多 AI 對話 Token，專案拆分為以下獨立檔案：

```text
finpulse-pro/
├── index.html             # [頁面 1] 資金定位樹（銀行/平台→細項戶口→幣別）與股市級現金流看盤圖表
├── cashflow.html          # [頁面 2] 一般入帳/支帳記帳、跨幣別換匯轉帳（獨立扣除手續費）與明細流水帳
├── holdings.html          # [頁面 3] 已購入國債/定存/期貨/IPO 持倉管理、到期倒數與一鍵結算入帳
├── calculator.html        # [頁面 4] 事前三情境收益試算機（最低/中價值/最高利率）與帶日期本機暫存草稿
├── accounts.html          # [頁面 5] 銀行戶口、投資平台 App（如富達、IB）與各平台預設手續費規則設定
├── app.js                 # [核心引擎] 共用狀態管理、動態幣別登錄（含 AUD）、本機匯率表與頂部導航/KPI 渲染
├── README.md              # 專案架構說明與 GitHub Pages 部署指南
└── AI_PROMPT_CONTEXT.md   # 專屬 AI 協作上下文提示詞（未來修改單一頁面時貼給 AI 以大幅節省 Token）
```

## ✨ 核心設計與省流量原則

1. **多幣別原幣核算 + 動態幣別擴充**：
   - 內建 `HKD`、`USD`、`AUD`（澳元）、`JPY`、`EUR`、`CNY`、`GBP`、`SGD`，並可隨時在「幣別與匯率」彈窗新增任意自訂幣別。
   - 遇到尚未填寫匯率的幣別，系統會安全標示「未設匯率 / 匯率待填」，不影響原幣帳目加減。
2. **三層資金定位樹（解決「不知道錢在哪」）**：
   - 總結餘支援「原幣分組」與「折合基準幣」切換；細項依 **銀行 / 股票 App → 細項戶口 → 幣別** 分層展開。
3. **跨幣別換匯與獨立手續費核算**：
   - 換匯轉帳精準加減兩邊原幣餘額，但**不會**灌水日常收入/支出圖表；手續費支援獨立幣別與獨立扣款戶口。
4. **0 雲端讀寫的本機試算暫存**：
   - 事前三情境試算結果與匯率表均存於瀏覽器 `localStorage`，不消耗 Google Cloud 每日免費讀寫額度。

## 🚀 3 分鐘免費上架 GitHub Pages（手機 + 電腦通用）

1. **建立倉庫**：登入 GitHub，點擊右上角 `+` → `New repository`，輸入倉庫名稱（例如 `finpulse-pro`）。
2. **上傳檔案**：點擊 `uploading an existing file`，將上述所有 `.html`、`app.js` 與 `.md` 檔案上傳至倉庫根目錄並 `Commit changes`。
3. **啟用 Pages**：進入倉庫 `Settings` → 左側 `Pages` → `Branch` 選擇 `main`（資料夾 `/ (root)`）→ 點擊 `Save`。
4. **安裝為手機 / 電腦 App**：
   - **iOS (Safari)**：開啟 GitHub Pages 網址 → 點擊底部「分享」→「加入主畫面」。
   - **Android / 桌面 Chrome**：開啟網址 → 點擊網址列或選單中的「安裝應用程式」。
